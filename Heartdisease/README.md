
# Heart Disease Prediction Using Machine Learning

## About the Project
This project predicts the possibility of heart disease using Machine Learning techniques.

It uses patient health information to generate predictions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
- Generative AI
- Streamlit

## Project Features
1. Heart Disease Prediction
2. Machine Learning Model
3. Generative AI Integration
4. Interactive Web Application

## Project Structure
- models/ - Saved ML model
- app.py - Application code
- genai.py - Generative AI code
- streamlit_app.py - Streamlit application
- heart.csv - Dataset
- heartdisease.ipynb - Jupyter Notebook
